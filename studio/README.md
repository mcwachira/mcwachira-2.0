# Sanity Studio for mcwachira portfolio

This is the Sanity Studio for the mcwachira portfolio Next.js application.

## Getting Started

1. Install dependencies:
   ```bash
   cd studio
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

   The studio will be available at `http://localhost:3333`

## Building

```bash
npm run build
```

## Deployment

```bash
npm run deploy
```

## Structure

- `/schemaTypes` - Sanity schema definitions
- `sanity.config.ts` - Sanity configuration
- `package.json` - Studio dependencies and scripts
